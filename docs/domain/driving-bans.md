# Запреты движения грузовиков

Решение 2026-10-01 (владелец): запреты движения по странам Европы — в бете, к релизу v1.0. Схема Европы по странам без интернета. Бесплатно: что сейчас и сегодня. Календарь на будущие дни — Premium (закрытие — Фаза 5, как у правок журнала).

Это справка, а не официальный источник: правила меняются, есть исключения (скоропортящиеся грузы, комбинированные перевозки, разрешения). Приложение это говорит и даёт ссылку на источник страны.

## Как устроено

- Правила — в движке, чистый Dart: `packages/tacho_engine/lib/driving_bans.dart` (`src/bans/`). Данные стран — `src/bans/countries.dart`, тесты — `test/bans/` (BAN-01…10).
- Правило: в какие дни (дни недели, праздники, канун праздника, каждый день, дни годового календаря), с какого по какое время по местному времени, где (все дороги, магистрали, отдельные дороги, часть регионов, не для всех машин), для машин тяжелее какого порога (3,5 / 7,5 / 12 т), в какую часть года.
- Время — местное время страны, переводится в UTC с учётом летнего времени ЕС (`BanZone`). Пасха — алгоритм Гаусса — Мииса, православная — для Болгарии, Румынии, Греции, когда их правила появятся в расчёте.
- Соседние и пересекающиеся запреты по всей сети склеиваются: в Швейцарии Рождество в пятницу и выходные — один запрет с 22:00 четверга до 05:00 понедельника. Частичный запрет (часть дорог, регионы, не для всех машин) показывается отдельно и не перекрывает полный.
- Годовые календари (Италия, летние дни Франции, Польши, Словении) известны до `calendarUntil`; позже — только постоянные правила, расчёт помечен «предварительно».
- Главная (UI-30): карточка с запретом в стране, где водитель сейчас, — конечной стране смены, иначе начальной, иначе стране по умолчанию, как «страна смены» на экране «Запреты движения». Показывается, только когда запрет по всей сети идёт («Запрет до 22:00») или начнётся в ближайшие 3 ч («Запрет с 13:00»), в том числе во время отдыха; частичный запрет и запреты на отдельных дорогах — только на экране страны, куда ведёт касание. Считается одна страна раз в минуту (`homeBanProvider`, `app/lib/features/home/ban_card.dart`).
- Масса — не выбирается (решение владельца 2026-10-02, раньше — класс в настройках): экраны показывают запреты для грузовика больше 12 т, под него попадают все правила. Движок по-прежнему считает классы до 3,5 / 3,5–7,5 / 7,5–12 / больше 12 т — пороги правил остаются в данных и видны в подписи правила («больше 7,5 т»). Прицеп не спрашиваем: у Германии, Австрии, Словакии запреты касаются и машин с прицепом — это сказано в справке страны.

## Обновлять

- Декабрь: календарь Италии на следующий год (декрет МИТ), летние субботы Франции (arrêté в декабре).
- Весна: летние даты Польши (по школьному году) и Словении.
- Январь: в Словакии — дни отдыха года (8.05 и 15.09 сняты только на 2026 год, закон 261/2025).
- Венгрия: `calendarUntil` — конец года, на который внесены праздники летом в пятницу (§ 2 (2)); после 20.08.2027 такой — 20.08.2032.
- После обновления: `checkedOn`, `calendarUntil`, тесты BAN-…, эта таблица. Новая версия приложения не нужна: после merge в `main` и зелёного CI сайт публикует правила, водители получают их в течение суток (раздел ниже).
- Сверка «сверить» — с официальными текстами: нужен доступ к сайтам стран (настройки сети среды: gesetze-im-internet.de, ris.bka.gv.at, legifrance.gouv.fr, fedlex.admin.ch, isap.sejm.gov.pl, gov.pl, slov-lex.sk, zakonyprolidi.cz, njt.hu, legilux.public.lu, police.public.lu, mit.gov.it, promet.si). Сейчас «сверить» — у Словакии и Венгрии (таблица выше).

## Обновление по сети

Решение 2026-10-03 (владелец): правила обновляются без новой версии приложения. Встроенные правила (`countries.dart`) — запасные: с ними приложение работает без интернета и сразу после установки.

- **Файл.** `https://tachogo.eu/bans/v1.json` — правила движка текстом JSON (`encodeBanData`, `packages/tacho_engine/lib/src/bans/ban_json.dart`) с подписью Ed25519. Собирает и подписывает `app/tool/bans_publish.dart`, публикует workflow «Сайт» (`.github/workflows/site.yml`) на Railway после зелёного CI на `main` — только проверенные тестами правила. В git файла нет.
- **Подпись.** Закрытый ключ — секрет `BANS_SIGNING_KEY` (32 байта в base64), открытый — в приложении (`banSigningKeys`, `app/lib/data/bans/ban_data_file.dart`). Подписан текст правил вместе со строкой `tachogo/bans/v1`. Чужая подпись, правка после подписи, незнакомый ключ — файл не принимается. CI на каждом PR проверяет, что ключ из секрета — тот, что в приложении. Ключ хранить в менеджере паролей; при утечке — новый ключ в `banSigningKeys`, выпуск версии, и только потом подписывать им (старые версии файл с незнакомым ключом не примут и останутся на своих правилах).
- **Формат.** Версия — `banDataFormat`, она же в имени файла. Поле, которого читатель не знает, пропускается; поэтому всё, без чего правило читается неверно (новый вид дней, исключение для класса машин), — только с новой версией: `bans/v2.json` рядом с `v1.json`, старые версии приложения читают свой файл. Ошибка в файле — неизвестное значение, невозможная дата или время, правило без дней, источник не `https`, нет страны из встроенных — и файл не используется целиком.
- **Приложение** (`app/lib/data/bans/`). Не чаще раза в сутки после удачной проверки — при запуске и на экране «Запреты движения» (приложение может жить в памяти неделями). Нет сети — в следующий раз, без ограничения. Скачанный файл хранится в БД с подписью (настройка `bans_file`, в перенос на другой телефон не входит) и проверяется при каждом чтении. Показываются скачанные правила, если их сверка (самая поздняя `checkedOn`) не раньше встроенных; иначе — встроенные: приложение обновили раньше, чем сайт. Стран, которых нет во встроенных, приложение не показывает: для них нет схемы и названий — новая страна приходит с версией приложения. Внизу экранов «Запреты движения» и страны — когда сайт в последний раз удачно проверен: «Правила обновлены 12.10.2026 в 09:12, проверяются раз в сутки» (настройка `bans_checked_at`); ещё ни разу — «Правила от 01.10.2026: обновятся, когда появится интернет». Дату сверки с источниками (`checkedOn`) водителю не показываем: старая дата выглядит как давно не обновлявшиеся данные (отзыв водителя 12.10.2026), а правила при этом самые новые.
- **Без секрета** «Сайт» не публикуется (ошибка), CI предупреждает. Ещё нужен секрет `RAILWAY_TOKEN` (`docs/site/README.md`, «Railway»), иначе «Сайт» падает на выкладке. Сайт не опубликован — приложения остаются на сохранённых или встроенных правилах.
- **Приватность.** В запросе нет данных о водителе; IP-адрес видит хостинг (Railway, сервер в ЕС; наш сервер журналов не ведёт) — сказано в политике конфиденциальности.
