# Сайт TachoGo

Лендинг в стиле «Дорожный плакат» (вариант B, выбран 2026-10-14; макеты — https://claude.ai/artifact/T8cb4mYFMJUmix7KVSVDnm). Публикует workflow «Сайт» (`.github/workflows/pages.yml`) после зелёного CI на `main`, вместе с политикой конфиденциальности и файлом правил запретов.

## Как устроен

| Что | Где |
|---|---|
| Тексты лендинга, по файлу на язык | `docs/site/<язык>.json` |
| Генератор: шаблон, стили, карта сайта | `app/tool/site_build.dart` |
| Шрифты (Unbounded, Onest, JetBrains Mono, Noto Sans Georgian — подмножества в WOFF2) и их лицензии OFL | `site/fonts/` |
| Политика конфиденциальности — пишется руками | `site/privacy/index.html` |
| Значки, картинка для соцсетей | `site/favicon.svg`, `site/favicon-32.png`, `site/icon-512.png` |

Генератор собирает при публикации, в git страниц нет:

- `site/index.html` — английская страница, корень сайта и `x-default`. Посетителя с другим языком браузера она сразу открывает на его языке (белорусский, казахский, киргизский — русская, как в приложении). Если человек пришёл с другой страницы сайта, например выбрал English в переключателе, — не переводит.
- `site/<язык>/index.html` — остальные 13 языков приложения.
- `site/sitemap.xml` и `site/robots.txt` — для Google Search Console.

Что берётся не из текстов, а из кода — чтобы сайт не обещал того, чего нет в приложении:

- надписи на телефоне — строки приложения из `app/lib/l10n/app_<язык>.arb`;
- страны с запретами, их число и вид запретов — данные движка (`europeBans`), названия стран — из `countryName` приложения;
- ссылка на Регламент 561/2006 на нужном языке EUR-Lex — как в приложении;
- цены Premium — `premiumPrices` в генераторе, формат числа и валюты — по языку.

Сайт ничего не грузит с других сайтов: нет cookies, счётчиков, внешних шрифтов и скриптов. Об этом — раздел «Сайт» политики. Если добавить аналитику или внешний сервис — сначала политика и баннер согласия.

## Поменять текст

1. Поправить строку во всех `docs/site/*.json` — ключи во всех файлах одинаковые (проверяет SITE-01).
2. Посмотреть локально:

   ```sh
   cd app
   dart run tool/site_build.dart ../site
   cd ../site && python3 -m http.server 8000
   ```

   и открыть http://localhost:8000/ru/. Собранные страницы git не видит (`.gitignore`).
3. `flutter test test/site/` — SITE-01.

Особые строки:

- `h1` — строки заголовка; слово TachoGo в нём выделяется жёлтым.
- `bans_count` — формы множественного числа по правилам языка (`one`, `few`, `many`, `other`), `{count}` — число стран.
- `disclaimer` — `{regulation}` заменяется ссылкой с текстом `regulation`.
- `mail_subject`, `mail_body` — письмо, которое открывает кнопка «Стать тестировщиком».

## Добавить язык

Язык сайта — язык приложения: сначала ARB в `app/lib/l10n/`, потом `docs/site/<язык>.json` и название языка на нём самом в `languageNames` генератора, локаль для соцсетей — в `_ogLocales`, код EUR-Lex — в `_eurLex`, если язык есть в ЕС.

## Свой домен

Адрес сайта — `siteBase` в генераторе и `privacyPolicyPage` в `app/lib/core/config/app_links.dart` (SITE-01 сверяет). При переезде на `tachogo.eu` сменить оба, `banDataUri` (`app/lib/data/bans/ban_data_file.dart`), добавить домен в Settings → Pages и в Play Console (`docs/beta/play-console.md`). Старый адрес на `github.io` GitHub сам переадресует на новый.
