# Дизайн TachoGo — вариант A «Кокпит»

Android, экран 412 dp. Тёмная тема по умолчанию, светлая — по настройке.
Нижняя навигация: **Главная · Журнал · Настройки · Ещё**.

Живой кликабельный прототип: https://claude.ai/artifact/JwAsjzmgjLTLzp9qCZJgeZ

- `tokens.json` — все токены (цвета, типографика, радиусы, отступы).
- Те же токены для Flutter — в `app/lib/core/theme/` (`app_colors.dart`, `app_tokens.dart`, `app_typography.dart`, `app_theme.dart`).
- `screens/` — скриншоты всех макетов (2x). Отрисованы запасным системным шрифтом, в приложении — Onest и JetBrains Mono.
- `source/` — исходная разметка макетов (`.dc.html`) и `canvas.json` с раскладкой холста. Файлы — справочные: в них точные тексты, отступы, цвета и логика состояний. Для просмотра используйте ссылку на прототип выше.

## Сетка и компоненты
- Отступы: поля экрана 16 · между карточками 8–16 · перед разделом 24–28 · внутри карточки 16.
- Радиусы: главная карточка 28 · карточки 24 · режимы 20 · кнопки 18 · плашки 16 · значки 14 · чипы 8.
- Касание: мин. 44 dp · строки списка 56 · кнопки 56 · режимы 88 — нажимать в перчатках.
- Строка лимита: полоса 6 dp, заливка цветом режима, риска 2×14 dp на каждом пороге.
- Состояния лимита: норма — цвет режима · < 30 мин до лимита — янтарная плашка · превышен — красная.
- Кнопки: основная (акцент), вторичная, опасное действие.

## Открытые вопросы
- Premium решён (`docs/premium.md`): правки и добавления в журнале, выгрузка PDF/CSV, перенос на другое устройство. Макет 15-Paywall (список функций) надо поправить, для переноса нужен новый экран (QR-код на старом устройстве, сканер на новом).
- Figma: перенос — через импорт HTML (например, плагин html.to.design) или вручную по прототипу.
