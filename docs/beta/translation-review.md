# Вычитка перевода

TachoGo переведён на украинский, польский, румынский, грузинский и узбекский (латиница) и на английский, немецкий, французский, испанский, итальянский, нидерландский, чешский и словацкий. Переводы машинные — просим водителей, для которых это родной язык, проверить, что всё понятно и звучит, как говорят в кабине и на контроле. Для языков ЕС особенно важен PDF-отчёт: его показывают инспектору в стране проверки, названия нарушений и статьи должны быть такими, как в официальном тексте регламента на этом языке.

## Для водителя-носителя языка

Вы получите таблицу `tachogo-<язык>.csv` — откройте в Google Таблицах (Файл → Импорт) или Excel. Каждая строка — одна надпись в приложении.

| Колонка | Что в ней |
|---|---|
| id | Служебный номер строки — не трогать |
| section | Где в приложении: Home — главная, Journal — журнал, Settings — настройки, Notifications — уведомления, PDF report — отчёт для инспекции … |
| context | Пояснение, если есть |
| russian | Русский текст — как задумано |
| numbers | Для слов с числом: с какими числами эта форма («1, 21, 31…» — «1 година», «2, 3, 4, 22…» — «2 години») |
| translation | Текст в приложении сейчас |
| **correction** | Сюда — ваш вариант, если текущий плох. Хорошо — оставьте пустым |
| **comment** | Сюда — вопрос или замечание |

Правила:
- `{time}`, `{hours}`, `{date}` в фигурных скобках — места для чисел и времени. Оставьте их как есть, можно переставить в другое место фразы.
- `[[days]]` — место, где стоит число с правильной формой слова. Тоже оставить.
- Проверяйте смысл правил: статьи регламента, «сокращённый отдых», «компенсация» должны звучать так, как их называют инспекторы и фирмы в вашей стране.
- Лучше проверять с приложением в руках: выберите свой язык в «Настройки» → «Язык».

Заполненную таблицу отправьте обратно. Можно частями.

## Вопросы водителям из Казахстана, Кыргызстана и Беларуси

Сейчас для вас приложение на русском. Ответьте, пожалуйста:

1. Удобно ли вам пользоваться TachoGo на русском? (да / скорее да / скорее нет / нет)
2. Хотели бы вы казахский / кыргызский / белорусский? Стали бы переключаться?
3. На каком языке с вами говорят в фирме и на контроле?
4. Есть ли места в приложении, которые на русском непонятны?

Ответы решают, нужен ли перевод (`docs/PRD.md`, решение по Tier 1 от 2026-09-28).

## Для разработчика

```bash
cd app
dart run tool/l10n_review.dart export              # build/l10n_review/tachogo-<язык>.csv
dart run tool/l10n_review.dart import ~/Downloads/tachogo-uk.csv
flutter gen-l10n && flutter test test/l10n test/design/screen_conformance_test.dart
```

`import` берёт язык из имени файла (`tachogo-uk.csv`, `tachogo-uk (1).csv`) или из `--lang`. Строки без исправления не меняются. Исправление, в котором пропала подстановка `{…}`, метка `[[…]]` или скобка, не применяется — оно в отчёте, его поправить вручную. Комментарии печатаются списком — ответить водителю. Проверка экранов на каждом языке (360 dp, шрифт ×2) покажет, если новая строка не влезла, — переносим, а не сокращаем.
