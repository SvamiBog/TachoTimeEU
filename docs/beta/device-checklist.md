# Чек-лист телефона (DEV-01, DEV-02)

Для тестировщика беты: работает ли TachoGo в фоне и приходят ли уведомления на вашем телефоне. Займёт рабочий день, большая часть — просто вести смену. Что проверяем и почему — `docs/background.md`, «Проверить на устройствах».

Заполните таблицу (скопируйте в сообщение или отметьте в распечатке) и отправьте вместе с «Сообщить о проблеме» — отчёт сам добавит модель телефона, версию Android и разрешения.

## Телефон

| | |
|---|---|
| Производитель и модель | |
| Версия Android и оболочки (MIUI / HyperOS, EMUI, One UI, ColorOS …) | |
| «Экономия батареи» для TachoGo выключена | да / нет |
| «Автозапуск» разрешён (Xiaomi, Huawei, Honor, Oppo, Vivo) | да / нет / такого нет |
| «Точное время уведомлений» включено (Android 14+) | да / нет / такого нет |
| Автоопределение вождения включено | да / нет |

## Проверки

Результат — «да», «нет» или время. Если «нет» — сразу «Сообщить о проблеме».

| # | Что сделать | Что должно быть | Результат |
|---|---|---|---|
| 1 | Включить «Вождение», закрыть TachoGo смахиванием из списка приложений, подождать 10 мин | Уведомление TachoGo с таймером осталось и обновляется | |
| 2 | Экран выключен, телефон лежит неподвижно час и больше (стоянка), затем «Вождение» | Уведомление «скоро перерыв» пришло. Время по таймеру и фактическое — записать | |
| 3 | Вождение 4:30 без перерыва (по TachoGo) при закрытом приложении | Уведомление о превышении — через минуту после 4:30. Опоздание — записать | |
| 4 | Перерыв 45 мин | Уведомление «перерыв засчитан» | |
| 5 | Перезагрузить телефон во время смены, приложение не открывать 30 мин | Уведомления о лимитах приходят; уведомление сервиса (Android 13 и ниже) вернулось само | |
| 6 | Обновить TachoGo из Play Маркета во время смены (если придёт обновление) | Журнал на месте, уведомления приходят | |
| 7 | Автоопределение: проехать от стоянки | «Вождение» с начала движения, а не с момента, как заметили | |
| 8 | Автоопределение: остановка на 3+ мин | «Другая работа» с начала остановки | |
| 9 | Автоопределение: пробка, светофоры | Режим не скачет | |
| 10 | Автоопределение: на отдыхе поехать пассажиром (или паром) | Только предложение «Вождение?» с кнопками, режим сам не меняется | |
| 11 | Кнопки «Вождение» / «Нет» в уведомлении | Журнал меняется, приложение видит запись | |
| 12 | Расход батареи за смену (Настройки → Батарея → TachoGo) | Процент за смену — записать | |
| 13 | Расход батареи за ночь на стоянке | Процент за ночь — записать | |
| 14 | Пересечь границу с другим часовым поясом (или сменить пояс в настройках) | Время в уведомлении и на главной — местное, остатки не изменились | |
| 15 | Автоопределение включено, экран выключен, телефон не трогать: стоянка 30+ мин, потом поехать, потом остановиться на 3+ мин. После каждого этапа включить экран и сразу посмотреть уведомление, не открывая TachoGo | «Вождение» — с начала движения, «Другая работа» — с начала остановки (как в пунктах 7 и 8); таймер в уведомлении верный сразу после включения экрана, а не через минуту | |
| 16 | Посмотреть на значки TachoGo: в строке состояния, когда есть уведомление (о лимите или автоопределения); иконку на рабочем столе; экран при запуске | В строке состояния — белое кольцо со стрелкой, а не белый квадрат или круг; иконка и экран запуска — то же кольцо на тёмно-синем; с тематическими значками Android 13+ — кольцо в цветах обоев | |

## Для разработчика

Результаты переносить в таблицу «Проверено на устройствах» в `docs/background.md` (модель, Android, оболочка, пункты, опоздание уведомлений). DEV-01 и DEV-02 в `docs/testing.md` отмечаются, когда пройдены хотя бы Xiaomi (HyperOS), Samsung (One UI) и Huawei или Honor, с точными будильниками и без.
